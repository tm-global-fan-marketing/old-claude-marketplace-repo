# Marketing Wizard

This is a thin pointer, not the skill's content. Before routing anything, fetch
the live Marketing Wizard Confluence page (`657621734`, GB2CM) via Confluence
MCP and follow it exactly — including its routing priority, its registry and
routing table, and its rule on when a clarification question is warranted. The
registry and routing table are a derived view regenerated from the destination
skills' own live pages, so they are read live and never answered from memory.
Do not route, or answer, from this description or from a prior fetch.

Once a destination is chosen, fetch that skill's own Confluence page live and
follow it. This wrapper and the Marketing Wizard page hold none of a
destination skill's intake, methodology, writing rules, output structure or
Source of Truth logic — that skill owns all of it, and asks for whatever it
still needs itself.

Three failure cases, all of which are stated rather than worked around:

- **A page can't be reached** — stop, name the page, and ask whether to wait or
  to proceed with the gap flagged. Never fall back on training data for brand,
  legal or compliance content, and never guess at what skills exist in the
  registry.
- **A page is reached but is empty, or doesn't cover the request** — say so
  plainly and don't fill the gap. Never invent a destination, and never offer
  the nearest working skill as a substitute for one that doesn't exist.
- **A page is gone — deleted, archived or merged** — say so. This needs the
  skill's owner to repoint it; waiting won't fix it.

Source page owners set the rules for their subjects and never sign off on
individual outputs. Every output still needs a human to review it before use —
the person who asked for it or their team, on the terms the destination skill
sets, never the owner of a source page.

This skill's description above is a derived view of the Confluence page's
Section 2 (WHEN IT RUNS). If Section 2 changes materially, the description must
be regenerated to match — never hand-edited independently.

Status, ownership and any open governance items live on the Confluence page and
are not recorded here, because a status held in two places drifts. Read them
there.
