# Content Creator

This is a thin pointer, not the skill's content. Fetch the live Confluence page below and follow it in full — its trigger test, source-of-truth reads, the nine Campaign Messaging Plan fields, the asset selection step, both requester approval gates, the supported asset set, the coherence rules and the publication step. Do not answer from this description or from memory of a prior fetch.

**Confluence page (fetch live before every use):** https://confluence.livenation.com/spaces/GB2CM/pages/657621183

Copy rules are not held here and not held on that page either — it reads Backstage Writer's live page and follows it for tone, voice, style and register. Content Creator owns the campaign; Backstage Writer owns the copy.

**Fonts shipped with this skill.** A `fonts/` folder sits alongside this SKILL.md (`skills/content-creator/fonts/` in the plugin) holding the Averta OTF files — Extrathin, Thin, Light, Regular, Semibold, Bold, Extrabold and Black, each with an Italic. Where a PowerPoint (.pptx) file is being created, always try to install these fonts before building it. If they cannot be installed, say so plainly rather than substituting another font without telling the requester. The rule itself is read live from the page; the folder is here because a font file cannot be fetched from Confluence.

**If a page cannot be reached:** stop, name the page, and ask whether to wait or to proceed with the gap flagged. Never fall back to training data for brand, legal or compliance content. If a page is reached but empty, say so and don't fill the gap — and where the empty page is the product the campaign is built around, stop rather than building on an empty source.

Every output carries `All outputs are drafts and require human review before use`, and publication to the Google Doc approves nothing — those rules are read live from the page.

This skill's description above is a derived view of the Confluence page's trigger definition. If that changes materially, the description must be regenerated to match — never hand-edited independently. It must never be rewritten around an asset count, and must never enumerate products, markets or audiences.

Status, ownership and any open governance items live on the Confluence page and are not recorded here, because a status held in two places drifts. Read them there.
